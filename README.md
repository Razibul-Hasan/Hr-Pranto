# Hr-Pranto

Portfolio website for Mohshin Imam Pranto, HR Generalist in Dhaka, Bangladesh.

Built with Next.js (App Router), React, TypeScript, Tailwind CSS, Three.js and GSAP.

## Run locally

```bash
npm install
npm run dev     # http://localhost:3000
npm run build   # production build
npm run lint
```

## Deploy

Import the repository on [Vercel](https://vercel.com) and deploy with the defaults.
If you add a custom domain, set `NEXT_PUBLIC_SITE_URL` to it so the share preview and canonical links use the right address.
